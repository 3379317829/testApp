# 掌上猪科 · 校园活动与机会聚合

> 珠海科技学院计算机协会软件部 2026 年秋季纳新第二轮考核作品
> 考核题目：AI Agent 产品实战 ｜ 数据来源：题目所给校园活动与机会模拟信息（26 条）

## 产品名称

**掌上猪科**（"猪"取"珠"的谐音，口语化、降低距离感）

## 主要解决的问题

校园活动与机会信息散落在学院通知、学生群、个人转发里，新生尤其容易：

- **看不懂**：一条信息里时间、对象、报名方式混在一起，还有"补充通知"推翻了原通知；
- **赶不上**：报名截止时间静默过期，或其实"可现场候补"却以为没戏了；
- **误信低质信息**：学生个人发布的内容里混着疑似兼职诈骗与商家推广。

掌上猪科把这些信息统一结构化，用**状态引擎 + 来源分级 + 可信度评分 + 资格适配**帮同学快速判断：
**今天能做什么、我够不够格、什么时候截止、这条信息靠不靠谱。**

## 核心功能

1. **学号登录与实名认证** —— 登录使用学号与「我的珠科」APP 的登录密码，由学校统一身份认证服务核验；账号采用实名制，同一学号仅可绑定一个账号，未登录不可浏览与发布。账号区分「已实名 / 未实名」，未实名账号不能发布活动、报名或登记参加活动；实名认证为单按钮流程：向统一身份认证服务发起核验，由服务端返回并自动绑定姓名与学号。尚未开通账号的用户可在登录页用学号发起核验，核验通过后自动开通账号并登录，无需另外注册（当前版本未接入该服务，由本地规则模拟返回结果，页面上已作说明）。
2. **活动发现与状态引擎** —— 按当前时间实时计算"进行中 / 今日开始 / 即将截止 / 已截止可候补 / 已结束待回放 / 长期有效 / 待定"，支持搜索、多维筛选与分页浏览（每页 8 条）。
3. **活动详情结构化解读** —— 面向对象、参加要求、报名方式、预估费用、招募人数、发布方逐项列出；材料未提供的信息统一显示为「无」，不做推断。
4. **关联通知合并** —— 同一活动的多条通知（如 01↔09、03↔20）自动合并展示，并标出已变更的时间与地点，避免看到失效信息。
5. **收藏与报名闭环** —— 收藏、报名/意向登记、候补意愿，刷新或重开后保留（localStorage）。
6. **实名自主发布** —— 同学可自行发布活动或招募，需勾选实名发布承诺后方可提交；发布内容直接进入发现页列表，并标注「学生个人发布」与发布者实名信息。
7. **后台管理** —— 面向管理员的账号管理：账号总览统计、新增账号、封禁/解封、删除账号（同时移除其发布内容），并可查看任一账号的发布内容、下架违规内容。

登录页已标注以下账号，点击即可自动填入。登录标识为**学号**：

| 角色 | 学号 | 密码 | 说明 |
|---|---|---|---|
| 管理员 | `00000000` | `admin123` | 已实名；登录后可进入「后台」管理账号与内容 |
| 学生 | `20260101` | `123456` | 已实名（林晓），可体验实名发布与报名流程 |
| 未实名用户 | `20260315` | `123456` | **未实名**；用于体验限制逻辑：不能发布活动、不能报名或登记参加活动，需先完成实名认证 |

未实名账号登录后：发布页只显示实名认证引导，活动详情页的报名按钮替换为「去实名认证」；在实名认证页点击「获取实名信息并绑定」，即可由统一身份认证返回实名信息并完成绑定（当前为本地模拟），完成后可正常发布与参加活动。

账号数据保存在浏览器本地，仅用于展示登录、实名认证、实名发布与后台管理流程，不做真实身份校验，也不与学校系统对接。

## 自主设计的实用 / 创新功能

- **信息可信度与完整度评分**：按来源层级 + 必备字段完整度 + 可疑特征综合打分，并列出缺失字段，让低质信息一眼可辨。
- **资格适配（参加资格）**：设置年级、基础、每周可投入时间后，自动判定"符合 / 不符合 / 待确认"，把隐含门槛变成显式结论。
- **变更与冲突合并提示**：自动识别同一活动的原通知与补充通知，标注变更点。
- **实名发布与内容核查**：实名制约束发布行为，配合风险特征识别与后台下架，兼顾开放参与、信息价值与平台秩序。
