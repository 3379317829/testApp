# 掌上猪科 · 校园活动与机会聚合

> 珠海科技学院计算机协会软件部 2026 年秋季纳新第二轮考核作品
> 考核题目：AI Agent 产品实战 ｜ 数据来源：题目所给校园活动与机会模拟信息（26 条）

## 产品名称

**掌上猪科**（"猪"取"珠"的谐音，口语化、降低距离感）

## 主要解决的问题

校园活动与机会信息散落在学院通知、学生群、个人转发里，新生尤其容易：

- **看不懂**：一条信息里时间、对象、报名方式混在一起，还有"补充通知"推翻了原通知；
- **赶不上**：报名截止时间静默过期，或其实"可现场候补"却以为没戏了；
- **踩到坑**：学生个人发布的信息里混着疑似兼职诈骗和商家推广。

掌上猪科把这些信息统一结构化，用**状态引擎 + 来源分级 + 可信度评分 + 资格适配**帮同学快速判断：
**今天能做什么、我够不够格、什么时候截止、这条信息靠不靠谱。**

## 核心功能

1. **活动发现与状态引擎** —— 按当前时间实时计算"进行中 / 今日开始 / 即将截止 / 已截止可候补 / 已结束待回放 / 长期有效 / 待定"，支持搜索与多维筛选。
2. **活动详情结构化解读** —— 时间、地点、对象、报名、费用、名额逐项列出；材料没给的字段显式标注"未提供"，不编造。
3. **关联通知合并** —— 同一活动的多条通知（如 01↔09、03↔20）自动合并展示，并高亮"已变更"的时间与地点，避免看到失效信息。
4. **收藏与报名闭环** —— 收藏、报名/意向登记、候补意愿，刷新或重开后保留（localStorage）。
5. **学生自主发布** —— 同学可自行发布活动或招募，发布内容直接进入列表正常流程，并标注"学生发布 · 未验证"。

## 自主设计的实用 / 创新功能

- **信息可信度与完整度评分**：按来源层级 + 必备字段完整度 + 可疑特征综合打分，并列出"缺了什么"，让低质信息一眼可辨。
- **资格适配（我能参加吗）**：设置年级、基础、每周可投入时间后，自动判定"符合 / 不符合 / 待确认"，把隐含门槛变成显式结论。
- **变更与冲突合并提示**：自动识别同一活动的原通知与补充通知，标注变更点。

## 运行方式

纯静态前端，**零依赖、零构建**：

```bash
# 方式一：直接双击 index.html（或拖进浏览器）
# 方式二：起一个本地静态服务（推荐，行为与线上一致）
python -m http.server 8000
# 然后访问 http://localhost:8000
```
